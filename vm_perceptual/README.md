# VM-Perceptual：第一次真实感知监督地图实验

执行顺序以[项目路线图](../ROADMAP.md)为准：先完善音频定位与相似音色检索；跨解析器统一接口、语气扩展和同人不同声线关联暂缓扩展。

这是音频→坐标的研究实现，目标为不同人的正常声线听感相似度，不是身份分类。数学结构与文献在[RESEARCH.md](RESEARCH.md)，预先固定设计在[PROTOCOL.md](PROTOCOL.md)，部署在[AUTODL.md](AUTODL.md)。

## 结果应怎样理解

100位JVS说话者，400段正常语音＋40段假声诊断，60/20/20人隔离。基于公开2451对、24510个原始听感评分；训练只用训练人内部配对，开发与测试每性别各45对。

开发集选择514参数的16维声学头。最终测试同性别听感SRCC均值0.413，节点bootstrap区间约[0.089,0.638]；不训练的完整声学基线为0.518。因此**没有证明新训练超过基线**，不能推荐为准确的最终产品。开发最优与测试最优不一致，保留开发选择，不倒过来挑测试赢家。

这是阶段上的变化：此前主要验证物理参数及身份代理，现在已实际训练“声音特征→感知距离”，并能对单条音频输出坐标。代码和研究训练可部署，语气基准化与同人多声线关联仍未实现。

## 短音频与显示维度

固定模型对20位测试人的中心截取，1/2/4秒与整句坐标的中位距离约1.00/0.68/0.48（单位向量欧氏距离，范围0–2）。全都可计算，但短音频漂移明显。不能将可输出坐标误称可靠定位。

二维显示保留69%的5近邻，三维71%，八维83%，16维100%（相对模型本身的几何，非人耳正确率）。更多显示维度能减少投影损失，但训练表示越大不一定越准确。

## 同音频跨解析器

同段音频在相同CPU管线中重复解析，坐标最大差0。用ECAPA/WavLM线性适配到本地图，80条留出录音中位坐标误差约0.77/0.74，没有精确同点；这只评价本次适配方法。统一坐标协议可实现，不能假设各解析器天然返回同一数字。详见[COORDINATE_STANDARD.md](COORDINATE_STANDARD.md)。

## 入口与证据

- prepare_sources.py / fetch_jvs.py：固定来源、预定子集、CRC和SHA256。
- extract_features.py：冻结前端；前端本身不读感知或身份标签。
- dataset.py / train_map.py：仅训练人拟合标准化和PCA，小型感知头及恢复。
- evaluate_map.py：先锁开发选择，再最终测试；包含未训练基线。
- infer.py：音频输入、版本化坐标与固定显示投影。
- map_index.py：固定模型录音索引，按完整音色向量检索，默认排除相同音频；拒绝不同模型版本混用。
- test_pipeline.py：防标定泄漏、距离性质、严格checkpoint加载等检查。
- results/REPORT.md：全部候选，保留负面结果。

权重、音频、特征缓存不在源码包内。原始评分和JVS来源需引用原作者，未获得跨性别感知评分，也没有模仿者配对真值，不能将结果推广到任意声线/语言/语气。
