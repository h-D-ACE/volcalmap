# 音色地图与可选语气坐标：产品和模型约定

当前执行优先级见[ROADMAP.md](../ROADMAP.md)：先完善音频定位与音色近邻检索。下面保留的语气和身份关联是后续目标；跨解析器统一接口不作为第一阶段前置条件。

2026-11-17，按用户A–D确认及同人多声线关联补充更新。数学声学测量是支撑模块，最终目标始终是音频自动定位和感知相似检索。本文件是目标约定，不表示以下接口均已实现。

## 期望输入与输出

输入：单人语音音频，语言可选；产品应自动处理语音区间和内容，不能要求用户为每段音频手工填写元音边界。现在的强制对齐只是验证工具，尚不满足这个产品入口。

可选输入：同一声线的参考录音、参考语气及其可靠性。参考必须与目标声线匹配；同一演员另一角色的平静录音不能自动当成该声线基准。无参考时仍允许分析，但基准化估计可以返回高不确定性或insufficient_evidence，不能承诺准确恢复。

输出示意（不是当前已训练的结果）：

```json
{
  "sample_id": "独立记录ID",
  "model_version": "锁定的编码器及坐标版本",
  "timbre": {"vector": ["示例：32维"], "uncertainty": "测量置信范围", "status": "valid或insufficient_evidence"},
  "prosody": null,
  "coverage": {"voiced_seconds": "秒数", "phone_support": "可靠发音条件"}
}
```

开启语气输出时prosody附带独立的向量和可靠性。32维音色、8维语气只是首个容量假设，维数最终由留出验证和压缩损失决定，不要求语气只能一个标量。语气可包括节奏、起伏、力度、情感与说话方式，情绪类别标签只覆盖其中一部分。

## 坐标意味着什么

令 E(x) = (z_t, z_p, uncertainty)，其中 z_t 属于音色空间，z_p 属于跨音色共享的语气空间。相似音色的z_t接近；不同音色仍可能有相近z_p。同一段录音在同一模型版本下输出应确定；同一声线跨内容/设备的坐标允许小幅随机漂移，并需要量化。

“每个音色有自己的位置”是定位目标，不意味着有限带噪音频可保证数学上唯一识别所有人。不同人也可以有相似音色，同一个人可以演绎不同声线。数据库唯一性使用sample/voice ID；坐标服务于可度量的相似关系，不能把身份分类结果直接当音色真值。

感知定义明确优先：如果B模仿A且听起来足够相似，二者音色位置应接近，不能因身份不同强行推远。同一人的两种声线如果听起来不同，应允许分开。感知证据需要控制文本/语气条件、重复性与听者差异；不能由身份准确率替代。

地图的真实距离在高维计算。2D/3D图仅可视化，高维邻近可能投影失真。正式模型需固定投影/版本，新增音频直接映射，避免每添加一条音频就重新布局并改变旧坐标。

显示接口应支持display_dimensions=1/2/3及展开更多维度。语气可由多维向量经固定函数投影为一个显示数值（例如3D视图高度），同时保留完整向量与展开功能；一个显示数值不等于完整语气。对一般多维数据，连续压缩为一维不能保证无损保留所有邻近与区别。每种投影报告邻居保留率、距离失真、适用数据范围和projection_version；PCA解释方差不冒充感知准确率。默认检索使用全维，切换显示维度不改变检索结果。音色与语气可以联合可视化或采用联动视图，属于同一声音空间。

## 语气匹配开关如何工作

默认只计算/使用 d_t = distance(z_t(query), z_t(candidate))。开关打开时：

1. 先按音色距离取候选集（top-K或经验证的半径）。
2. 仅在此集合内按语气距离d_p排序；输出两个独立距离。
3. 缺少有效语气时明确提示，不能当成语气距离0；也不能让音色差很大的候选靠语气分数跳到最前。

`voice_space.py` 已实现这个与编码器独立的检索约定，并测试：开关关时排序不依赖语气；开时只改变音色候选内排序；不同音色相同语气可有零语气距离；混用模型版本拒绝。该模块没有假造音频坐标，需以后接入经过验证的编码器。

## 新增：语气基准化开关与条件比较

这是独立于语气匹配的第二个控制：

- observed：按当前实际听到的声线比较，保留语气引起的听感变化。
- reference：估计该声线在共同参考语气p0下的音色。该开关可以改变所显示/比较的音色位置，必须标记模式。
- target：把各声线放在相同指定语气p*条件下比较；基准化是p*=p0的特例。

候选模型（待验证）：z_obs = F_theta(u_v,p,c,l,d) + epsilon，其中u_v是声线潜变量，p为语气，c/l/d分别表示内容、语言与设备条件。对内容与设备控制后的局部模型可写 z_obs≈u_v+B(u_v)·[phi(p)-phi(p0)]+epsilon。B允许随声线变化，不能假设所有人共用一个准确的平移向量。

先估计 q(u_v | x, optional_reference)，再计算基准或目标条件的预测分布，而非无条件从观察值减去固定数。参考语气须定义及版本化，不是物理上唯一的“本来声音”。不必先生成还原音频才可得到特征坐标；若使用重合成，应分开测生成器失真。外推到没有支持的发声方式时，允许拒绝给出可靠坐标。

原始坐标保留，派生坐标带mode、reference_id、target_prosody、uncertainty、model_version；只比较同一模式/基准条件的距离。语气匹配开关使用哪个语气向量也须说明：默认保留原录音的实际语气，而非把基准化后的共同p0当作大家语气相同。

上述是产品设计，voice_space.py目前只实现语气匹配，不包含基准化推断。

## 后续探索：同人多声线关联

感知音色地图与身份关联分开。提供候选关系分数S_same_person(x_i,x_j,optional_enrollment)，在不同声线之间建立带不确定性的关联边；不通过合并或移动音色点来强迫同人的声线靠近。相似的模仿者可在音色图中相邻，但身份关系未必相同。

检索已存在的录音作为同人候选，与生成或预测某个人尚未出现的声线，是不同任务。前者可探索身份编码、跨声线配对训练与校准；后者从一段声线不能唯一确定，只能提出条件化候选分布，不能宣称恢复某人的全部声线。

应专门测试同人跨声线召回、不同人模仿的误关联率、未见人物和声线、置信校准及拒绝判断能力。身份标签只监督这个独立分支，不替代感知音色目标。此功能尚未实现。

## 训练分阶段

阶段0：物理测量与质量。已知参考/合成参数→小网络预测F1–F3及后续不确定度。`train_physics.py` 当前仅包含F1–F3预测，不含完整音色/语气训练。用于检验神经网络是否能比固定Burg更稳健地测量，而非将这三个数直接命名为最终音色。

阶段1：音色编码。共享语音编码器或小型时频网络→音色头；物理参数作为辅助监督、同发声跨通道一致性和已知声学干预作为约束。需要保留声线差异，不可以只用同人正样本把其所有角色声线强行合并。可先冻结预训练编码器只训练小头，验证是否比现成嵌入和声学基线更好。

阶段2：语气头。跨说话者相同表达作为正关联，同一说话者不同表达作为区分；同时控制文字内容/语言/音高范围和设备。让语气分支少编码身份，但不宣称两个因素能够物理上完全独立。强情感可能也改变声源音质，必须定义哪些变化归音色、哪些归表达。

候选联合目标：

L = λphys L_masked-physical + λchannel L_same-event-consistency + λt L_timbre-metric + λp L_prosody-metric + λquality L_quality。

物理监督只在已知参考可靠且有定义的参数上生效；缺失保留掩码。反坍缩/已知不同声学配置约束防止所有输入映到一点。身份标签、情绪类别和物理误差分别只是部分监督，不能替代最终音色/语气相似性验收。

## 自动化可继续做的事与训练前验收

可以自主继续：下载许可允许的公开数据、按既定划分扩展验证、修复代码、运行CPU/GPU工程检查、比较方法、准备GitHub代码包与AutoDL命令。遇到一种方法无效时按实验结论换方法并保留失败结果。

准备好代码包不等于可以正式训练通用音色模型。建议的阶段门槛（工程目标，非行业标准；本轮提出后须用新数据验证）如下：

|关卡|需要看到的证据|建议初始目标|
|---|---|---|
|工程|数据哈希、按人分组、可恢复训练、推理确定性、版本一致|检查全部通过|
|物理测量|独立标注/合成两类误差；全部预选样本分母、每人/元音分层|长自然元音完整覆盖≥90%，≥95%参考测量点误差≤10%；尾部不能靠删样本消失|
|设备/内容鲁棒性|新说话者、新句、同次双麦；以后增未知设备和跨日|相同分母下较基线降低至少10%重复距离，群体/元音不能出现明显系统退化；报告按人置信区间|
|音色意义|声学干预方向正确、同人多声线、不同人相似声线、对比现成嵌入|不只提高身份识别；最终听觉相似性评测独立于训练并有重复标注一致性|
|语气意义|留出说话者跨音色语气匹配，留出文本/语言|优于F0/能量/节奏基线；匹配开关不改变坐标，基准化开关改变条件且报告不确定性|
|产品入口|只提供音频即可定位、拒绝与不确定性可解释|无须人工文本/音素边界，长短/噪声/混音条件均测试|

允许在最终关卡全部达标前进行有明确定义的小规模模型实验，以回答网络是否能解决测量问题；不能把这样的实验称为已可用的通用地图，也不应投入大规模云训练。最终感知目标不能只通过“人耳一定不如机器”来绕过，因为我们要测的是音色/语气相似性的定义本身。
